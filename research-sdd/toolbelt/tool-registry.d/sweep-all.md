### sweep-all (#2664)

Intended divergences of `rsdd sweep all` (the Go port behind `sweep-all.sh`) from the frozen legacy script. Everything else is byte-identical on stdout, stderr and exit code, pinned by a differential against the sha-pinned script (`internal/sweep/all_diff_test.go`, `!nodiff`) and by goldens recorded from it (`testdata/all/golden/cases.txt`, replayed without bash). The rows below are the tests of `internal/sweep/all_divergence_test.go` and `all_unit_test.go`. The parts that stay identical on purpose: the eight scripts and their order (`allscripts.go`), the banner and summary text, `FAIL  <name> (script not found: <path>)` on stderr for a missing script, `(exit N)` for a plain failure and `(timed out after <N>s)` for a timeout, stderr merged into stdout in the order written, the caller's directory and environment, and exit 0 only when all eight pass.

| Divergence | Legacy script | Port |
|---|---|---|
| A script that itself exits 124 | `rc == 124` was read as a timeout: `FAIL <name> (timed out after Ns)` for a script that finished at once. | `FAIL <name> (exit 124)`; only `core/proc`'s own stop reason says "timed out". `TestAllExit124IsNotATimeout`. |
| A script that ignores SIGTERM | `timeout` sent TERM and waited: one `trap '' TERM` script hung the aggregator (and the session start) for ever. | TERM, then KILL to the whole process group after the grace period; the failure is "timed out" and the script is gone when the run returns. `TestAllTermIgnoringScriptIsKilled`. |
| A script killed by a signal | `FAIL <name> (exit 137)` — the shell's 128+N, indistinguishable from a script that chose 137. | `FAIL <name> (killed by signal 9)`, summary `(signal 9)`. `TestAllSignalKilledScript`, `TestAllReportsEveryKindOfFailure`. |
| `RSDD_SWEEP_TIMEOUT` that is not a positive number of seconds | Handed to `timeout` as is: `abc` or `-1` failed all eight scripts with exit 125; `0` ran them with no bound; `2m` was accepted and printed `timed out after 2ms`; `1e3` and `inf` ran unbounded or for hours. | Plain decimal seconds only (`30`, `0.5`, `.5`), at most one year. Anything else is the 30 s default plus one stderr line `sweep-all: warning: RSDD_SWEEP_TIMEOUT "<v>" is not a positive number of seconds (at most one year) — using 30`, before the first banner; the exit code still reflects the scripts. An empty value is the default without a warning. `TestParseSweepTimeout`, `TestAllTimeoutReachesTheRunner`. |
| Output of a script | Unbounded: a script that looped on its output filled the terminal or memory. | At most 4 MiB per script; reaching it stops the script (`FAIL <name> (output exceeded N bytes)`, summary `(output cap)`) and the run continues. `TestAllOutputIsBounded`. |
| A shell that cannot be started | `timeout` or `bash` missing printed `FAIL <name> (exit 127)` (or 125) for each script. | `FAIL <name> (cannot start: <reason>)`, summary `(cannot start)`. `TestAllUnstartableShell`. |
| A process group that cannot be stopped | Not detectable. | `FAIL <name> (its process group could not be stopped: <reason>)`, summary `(not stopped)`; never a PASS. `TestAllReportsEveryKindOfFailure`. |
| Environment of the children | Inherited as is. | The caller's environment plus `RSDD_BIN=<this binary>` (`kit.ShimEnv`), so the scripts that are shims skip their source-fingerprint check and run this very binary; a preset `RSDD_BIN` is kept. `TestAllChildEnvironment`. |
| Non-executable script | The header promised `FAIL`, but the script was run with `bash`, so a script without the execute bit ran and passed. | Kept (the promise was never true): the script runs with `bash`. The real toolbelt's modes are checked by `tests/sweep-all.test.sh` case 11. |
| Arguments other than `--kit DIR` | Ignored: `sweep-all.sh --json` (or `--hook`, or any word) printed the plain-text report and exited 0, so a caller asking for machine output could not tell it got none. | Usage error before any banner: `sweep-all: unsupported argument "<arg>" (usage: sweep all [--kit DIR])`, exit 2. `TestAllCommandLine`. |
| Source of the eight names | A literal list in the script, read by `sweep-all.test.sh` and `pi-hooks.test.sh`. | `rsdd/internal/sweep/allscripts.go`; both suites read that file. `TestAllScriptsAreTheEight`. |

The subprocess list of the port (one child per script, in order; `TestAllSubprocessRecord`): `bash -c 'exec 2>&1; exec bash "$1"' sweep-all <kit>/toolbelt/<name>`, run in the caller's directory with a null stdin, under the per-script timeout and output bound.
