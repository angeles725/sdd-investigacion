### kit-writer-check (#2208)

| Tool | Description |
|---|---|
| `rsdd maint writer-check` (shim `maint/kit-writer-check.sh`) `--base <ref> [--head <ref>\|--worktree] [--teeth-log DIR] [--format report\|json] [--repo DIR] [--manifest-dir DIR] [--tolerate-stale-manifest] [--print-binding] \| --write-teeth-log DIR --base <ref> [--repo DIR] <suite>... \| --classify <path>...` | Writer-discipline check (kit issue #2208), run BEFORE the full gate. From the diff it lists each changed production script and the suites `tests/suite-impact.sh` maps it to (under a FULL escalation: the suites that name the file directly, falling back to the map, plus a `full-gate-needed` note), and requires one `--prove-teeth` log per required `*.test.sh` in `--teeth-log DIR` (named after the repo-relative suite path, `/` -> `__`: last summary `== N passed · 0 failed ==` with N>0, a teeth banner, no `  FAIL  ` line) else `missing-teeth <suite> <reason>`; each log starts with the binding header `# writer-check: head=… tree=…` (hash of the changed files) that `--write-teeth-log` writes, and a missing or different header is `stale-teeth <suite>`; `tests/writer-check-waivers.txt` (`<suite> <reason>`) waives a suite that cannot show teeth, reported `teeth-waived`; a changed script no suite names is `no-suite <file>`; an ADDED line that kills processes by name (pkill/killall, `kill -1` forms, pgrep/pidof into kill; command position in shell, argv/call forms in python/js; `# writer-check: allow-name-kill <reason>` opts out) is `name-kill <file>:<line>` (same verdicts as `templates/hook-pretool-pkill-guard.sh --strict-name-kill`, pinned by `tests/fixtures/kit-writer-check/name-kill-corpus.txt`). `--classify` prints whether a path counts as production (pinned to `parse-red-evidence.cjs` by `production-paths.txt`). `--write-teeth-log` runs the suites with `--prove-teeth` under `timeout` (`KIT_WRITER_CHECK_TIMEOUT`, default 900 s) and writes the logs. Exit 0 clean, 1 findings, 2 degraded. Read-only on the repo. Go port (kit issue #2212, Go port of the maint batch): `rsdd maint writer-check`, package `rsdd/internal/maint/writercheck` (args, classify, changes, udiff, binding, impact, required, waivers, teeth, namekill with its rules table, report, writelog: one responsibility each); the shim `maint/kit-writer-check.sh` exports `KIT_WRITER_CHECK_IMPACT` from its own directory. Pinned by a differential test against the frozen legacy script under `internal/maint/writercheck/testdata/legacy` (stdout, stderr and exit code over every mode, state and edge of the old suite, with goldens for the mutation run), by a Go test that walks every line of `name-kill-corpus.txt` and `production-paths.txt` (and compares `--classify` with `parse-red-evidence.cjs`), and by `tests/kit-writer-check.test.sh` against the shim. |

Intended divergences from the bash tool (each pinned by a Go test; everything else is byte-identical):

| Divergence | Why |
|---|---|
| grep, awk, sort, mktemp, timeout and sed are no longer dependencies; only git is probed up front and bash where it runs (`TestNoLongerNeedsGrepAwkSortMktempTimeoutSed`, `TestBashIsProbedWhereItIsUsed`) | the scan, the sorting and the temporary files are Go now |
| changed paths are read NUL-delimited and unquoted, and a diff hunk is read by its header counts: a path with a space or a quote, and an added line that itself starts with `++ b/`, are attributed to the right file (`TestNameKillAttributionToTheRightFile`, `TestAddedLineThatLooksLikeAFileHeader`, `TestHeaderPathsWithSpacesAndQuotes`) | the awk took the second word of the `+++` header and reset the file at any added `+++` line |
| a waiver line is read after its leading blanks, a blank line is skipped, and a reason keeps its tabs (`TestParseWaivers`) | the bash made a blank or indented line a reason-less or empty-suite waiver and cut a reason at its first tab |
| a suite that outlives `KIT_WRITER_CHECK_TIMEOUT` has its whole process group stopped (TERM, then KILL) and still exits 124 (`TestTimeoutStopsTheSuitesProcessGroup`) | `timeout` stopped only the direct child and left its background jobs running |
| without `KIT_WRITER_CHECK_IMPACT` the kit's `suite-impact.sh` is resolved like the portable hooks resolve it, and the degraded line says `(set KIT_WRITER_CHECK_IMPACT)` when none is found (`TestImpactScriptFallsBackToTheResolvedKit`) | the Go command cannot see the shim's directory; the shim exports the variable first |
| the log tree id is the git blob id computed in process (`TestBlobOfIsGitsBlobId`) | one `git hash-object --stdin` less; identical for sha1 repositories |
| a degraded exit is 2 with `degraded: kit-writer-check: <why>` on stderr, as before | unchanged: listed so the contract (never a zero) is stated next to the divergences |
