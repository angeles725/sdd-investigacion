### go-impact (#2613)

| Tool | Description |
|---|---|
| `rsdd maint go-impact [--repo DIR] [--wide N] FILE...` (no shim; called by `suite-impact.sh` in a later change) | Maps changed repo-relative files to the toolbelt bash files that reach the rsdd commands built from them. Package `rsdd/internal/maint/goimpact` (module, parse, closure, bashlex, bashheredoc, bashclass, bashscan, bashtree, blind, exempt, classify, reach, paths, run: one responsibility each). Parses `DIR/research-sdd/rsdd` with `go/parser` only (no `go list`, no build, no generated manifest) and the bash tree with a small quote-aware lexer. One block per FILE in input order, tab-separated: `NONE FILE go-test-only` / `NONE FILE no-bash-caller` / `NONE FILE no-command`, `SHIM FILE BASH GROUP NAME` (one per reaching bash file), `UNREACHED FILE GROUP NAME`, `BLIND FILE BASH CLASS`, closed by `CLOSURE FILE PACKAGES COMMANDS`; or `FULL FILE REASON`. After all blocks, one `CLASSES` line. Exit 0 when classification ran, 2 on a usage error or an unreadable module (`degraded: go-impact: <reason>` on stderr); an empty result for a non-empty input is never printed. |

How it decides (fail closed: whatever it cannot place is `FULL` with a typed reason, or a `BLIND` bash file):

| Input | Output |
|---|---|
| `*_test.go`, a file under `testdata/`, or a non-test file whose package is not built into the binary and defines no command (only test importers, e.g. `internal/testkit/*`) | `NONE ... go-test-only` |
| testdata whose module path (or `testdata/...` tail) a bash file names | `FULL ... testdata named by bash: <script>` |
| `go.mod`, `go.sum`, `Makefile`, `teeth-debt.txt` (the bridge suite reads it), `cmd/**`, `internal/cli/**`, `internal/commands/**` | `FULL` with the path class as reason |
| any other non-Go file of the module (e.g. an embedded `help.txt`) | `FULL ... unclassified module file`: a non-Go file is never a member of its package |
| any path outside `research-sdd/rsdd/` | `FULL ... outside the rsdd module` |
| a package file | reverse import closure over non-test edges, the commands defined in it (`cli.Command` literals with constant `Group` and `Name`), then the bash files that call them: `SHIM` per caller, `UNREACHED FILE GROUP NAME` per command no bash file calls (informational: no toolbelt suite can reach it, the Go jobs gate it) |
| a package file built into the binary (`cmd/rsdd` in its reverse closure), command package or not | the `BLIND` files are added to the selection (never `FULL`). When there is no `SHIM` and no `BLIND` line the verdict is `NONE FILE no-bash-caller` (commands, none called) or `NONE FILE no-command` (distinct from `go-test-only`) |
| a parse error, an unresolved command literal, or a closure of more than `--wide` (default 12) distinct bash files | `FULL` with the reason; the size is in the reason and in the `CLOSURE` line |

Recognised ways bash reaches a command (real-tree survey; the enumerator test fails when a form goes unseen): `rsdd_exec <group> <name>`, `rsdd_exec_hook <kind> <group> <name>`, `"$RSDD_BIN" <group> <name>` (also `${RSDD_BIN}`), `"$RSDD_REAL_BIN" <group> <name>`, and a literal `rsdd <group> <name>` (or `.../bin/rsdd`; unit-tested, unused by any script today). A single word naming an ungrouped command (`rsdd version`) resolves too. Scope: every `*.sh` and extensionless shebang file under `research-sdd/` outside the `rsdd/` module (its scripts are frozen fixtures). A suite that calls the binary directly is a caller exactly like a shim.

Every `RSDD_BIN` / `RSDD_REAL_BIN` mention in code (comments excluded) is classified by the bash tokens: **A** assignment, `export`, `declare`, `local`, `unset`, env prefix (not a call); **B** operand of `[ ]`, `[[ ]]`, `test` (not a call); **C** command position, also inside `$( )`, a pipeline, after `&&`/`||`, in `if`/`while` (a call); **D** argument position after any other command word, e.g. `timeout 60 "$RSDD_BIN" verify state`, `run_cap "$RSDD_BIN" ...`, `env -i ... "$RSDD_BIN"`, `go build -o "$RSDD_BIN"` (treated as a call); **unplaceable** inside `eval`, a `bash -c` string or a here-doc a shell executes. A C or D mention whose next two words are a registered group and name is an edge; any other C, D or unplaceable mention makes the file a **Go blind spot**. A file that mentions the binary, has no parsed call and names no shim (the basename of a bash file with a parsed edge) is a blind spot of class `empty-reach`; one that only exports the binary for shims it runs keeps its mapping and stays out.

A blind-spot file is printed `BLIND FILE BASH CLASS` for every Go change built into the binary (not only command packages) and never makes the change `FULL`. **Wide threshold, as chosen:** `--wide` counts the `SHIM` bash files only; blind spots are one fixed list per run and are counted apart (folding them in would turn every change `FULL`). The `CLASSES` line, `CLASSES A=<n> B=<n> C=<n> D=<n> unplaceable=<n> empty-reach=<n> blindspot-files=<n>` (tab-separated), counts over the whole scanned bash tree: mentions for A to unplaceable, files for the last two, so a zero is a measured zero (§7), not a scan that saw nothing. Deliberately, testdata -> `go-test-only` drops today's basename edges from module testdata to live scripts.

Pinned by (`internal/maint/goimpact`): `TestParserMatchesAssembledRegistry` (the commands recovered from `cli.Command` literals equal the commands of `internal/commands.Table`), `TestBashEnumeratorMatchesRegistryOnTheRealTree` (the classifier-derived blind set equals `testdata/go-blindspot.txt`, one `<path> <class>` per line: a marked file the list lacks fails, a stale entry fails; a stale exemption fails), `TestEveryMentionClass` (one case per class), `TestCountClassesOnAKnownTree`, synthetic-module tests for every classification and list edge, and a real-tree smoke test (`retro stage-issues` reaches `toolbelt/stage-retro-issues.sh`).

Declared exemption (`exempt.go`): `toolbelt/tests/rsdd-exec.test.sh` writes generic `rsdd_exec "$@"` shim templates into a fixture kit and runs them against stub binaries; it is not a blind spot, because the commands it really reaches are named explicitly in the same file. The traced-run check (static reach must contain traced reach) is what proves that exemption hides no edge.

Known limits (each over-selects or is listed, never silently under-selects): the `version` command lives in the registry package, which is in every closure, so it is attributed to no file change; the freshness hash that `rsdd_exec` compares changes with every non-test Go file, which this tool does not model; an assignment such as `real="$RSDD_BIN"` is class A by rule, so a later `"$real" verify state` is not attributed (a known alias hole).
