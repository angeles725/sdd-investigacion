### verify-state (#2457)

| Tool | Description |
|---|---|
| `rsdd verify state <target-dir> [--focus <slug>]` | Go port (kit issue #2457, epic #2270) of `verify-state.sh`; the registry row `verify-state.sh <target-dir>` above still describes what it checks and prints, byte for byte, and its legacy exit contract holds: 0 consistent, 1 inconsistency (a FAIL line; the command table maps its internal stale code to 1), 2 bad arguments, no `RESEARCH-STATE*.md` under the target, or an absent `--focus` slug. `verify-state.sh` is a compatibility shim that hands over to `lib/rsdd-exec.sh` and passes its own directory as `RSDD_TOOLBELT_DIR`, so the gap-drift check keeps running `check-gap-drift.sh` from beside the shim; without that variable the check prints its typed `WARN   gap-drift: degraded — check-gap-drift.sh not found` line. The shim is removed in phase 8. The frozen script and the libraries it sourced are the parity oracle of the Go differential tests (`internal/verify/testdata/state-legacy`). Intended differences: `jq`, `xargs` and `realpath` are no longer run (the settings are parsed in process, so the P8 `jq not found` and `realpath not found` degraded reports cannot occur and the containment check is always the exact `realpath` one); the helper libraries cannot be missing, so the exit-1 `cannot find helper` guards and the `degraded` branches for a failed `awk`/`grep` do not exist; stdout is released when the command ends while stderr is written as it happens, so a caller merging both with `2>&1` sees the stderr lines first; a bash test over an envelope integer beyond int64 (`[: N: integer expression expected`) prints no stderr line and is false, as before; an envelope integer with a digit 8 or 9 behind a leading zero aborts that state's remaining checks with bash's own message, prefixed `verify-state.sh: line 1114:` instead of the script path; the `check-gap-drift.sh` run is bounded by a 5-minute timeout. |
