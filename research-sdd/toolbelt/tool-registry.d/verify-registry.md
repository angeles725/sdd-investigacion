### verify-registry (#2362, #2363, #2364)

| Tool | Description |
|---|---|
| `rsdd verify registry [--json] [--kit <kit-root>]`, `rsdd verify registry-hook [--full] [--kit <kit-root>]` | Go ports (kit issues #2362/#2363/#2364, epic #2270) of `verify-registry.sh` and `verify-registry-hook.sh`; the registry rows `verify-registry.sh [--json]` and `verify-registry-hook.sh` above still describe what they check and print, and their exit contract holds: 0 report (findings never fail), 1 operational failure, 2 usage. Both scripts are compatibility shims that hand over to `lib/rsdd-exec.sh` and pass their kit root as `--kit` (the binary cannot see the shim's location); the hook is `rsdd_exec_hook sweep`, so an unavailable binary still exits 0 with a visible DEGRADED envelope. The shims are removed in phase 8. The hook-wiring checks run in process through `internal/core/hookwiring` and the opt-in session-budget check (`RSDD_REGISTRY_SESSION_BUDGET=1`) through `rsdd budget session` (wired by `internal/commands`), so no `lib/hook-wiring.sh` function and no `verify-session-budget.sh` run is involved (that file only has to exist beside the shim, as before). The frozen scripts and libraries (pinned by `SHA256SUMS`) are the parity oracle of the Go differential tests (`internal/verify/testdata/legacy/registry`). Intended differences, each pinned by a Go test: (1) an unreadable `TARGETS.md` is degraded input: `verify-registry: degraded: cannot read <path> ...; the registry was NOT reconciled` on stderr and exit 1 in both modes (the script read it as empty and, in the default mode, printed "no usable target paths" with exit 0); (2) a hook-wiring or session-budget check that could not run is counted, reported (`degraded: N hook-wiring/session-budget check(s) skipped`) and makes the exit code 1, never a clean report; (3) `--json` needs no `jq`, so the `degraded: jq not found` envelope and exit 3 do not exist; (4) no sourced helper can be missing or fail to define a function, so the exit-1 `cannot find helper` / `failed to define` guards and the awk-failure `script-state degraded` branch do not exist; (5) a stub `verify-session-budget.sh` beside the shim no longer takes part; (6) the hook always prints the JSON envelope (the script printed plain text without `jq`) and its compact filter measures lengths like gawk: characters under a UTF-8 `LC_ALL`/`LC_CTYPE`/`LANG`, bytes otherwise (mawk always counted bytes); (7) the finer points of the registry itself (U+001F in a message field, whitespace-only splitting of target paths, non-integer `RSDD_REGISTRY_TOL`, gawk-style cell length) are listed in the header of `research-sdd/rsdd/internal/verify/registry.go`. |
