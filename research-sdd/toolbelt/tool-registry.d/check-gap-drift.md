### check-gap-drift (#2645)

| Tool | Description |
|---|---|
| `rsdd verify gap-drift <target-dir> [--state <file>] [--threshold <pct>] [--all]` | Go port (kit issue #2645, epic #2270) of `check-gap-drift.sh` and `lib/gap-rows.sh`; the registry row `check-gap-drift.sh <target-dir> ...` above still describes what it checks and prints, and its exit contract holds: 0 no drift suspected, 1 drift or unparsed rows (findings only), 2 every operational failure. `check-gap-drift.sh` is a compatibility shim that hands over to `lib/rsdd-exec.sh` (the shim is removed in phase 8). The row, bullet and overlap rules are the typed `internal/core/gaprows` package (row splitting is `internal/core/gfm`, the block-file discriminator is `internal/core/kit`), shared with `rsdd verify state`, which now runs the check in process instead of spawning the script once per state file (`niagara-research` verify state 816 ms median to the figure in the PR). The result is typed (`OutcomeChecked`, `OutcomeEmptyInput`, `OutcomeNoRows`, `OutcomeNoPending`, `OutcomeDegraded`; errors are `*Error`), so absent, empty, no-match and degraded stay distinct for callers. `lib/gap-rows.sh` stays in place for `table-reader-parity.test.sh` and the `internal/core/gfm` differential, which still read it. The frozen script and both libs (pinned by `SHA256SUMS`) are the parity oracle of the Go differential tests (`research-sdd/rsdd/internal/verify/gapdrift/testdata/legacy`, `internal/core/gaprows/testdata/legacy`): the fixtures and seeded random corpora must print the same stdout, stderr and exit code. Intended differences, each pinned by a Go test in `internal/verify/gapdrift` (`gapdrift_test.go`): (D1) `--threshold` is read in decimal: the script's arithmetic read `010` as octal 8 and `08` aborted the loop mid-run, printing a clean `checked=1 suspects=0` and exiting 0; (D2) the nested-worktree prune is literal: a trailing slash on the target disabled it and a glob character in the target path widened it; (D3) block files of one block number are tried in bytewise path order (the script used readdir order, so which file defined a duplicated bullet depended on the filesystem); (D4) an `UNPARSED` line is printed whole (its first 90 bytes): the script's `read` cut it at its first tab; (D5) the row text of a `DRIFT?` line is cut at 90 characters (UTF-8, an invalid byte counts as one), where the script's `${text:0:90}` followed the caller's locale; (D6) a literal 0x01 byte in a cell stays 0x01 (the awk used it as its pipe placeholder and turned it into `\|`); (D7) the diagnostics bash and awk print on their own before the script's message (the `[` "integer expression expected" line for a huge `--threshold`, awk's "cannot open file" line for an unreadable block file) do not exist, the tool's own message and exit code are unchanged. A missing `lib/gap-rows.sh` or `lib/block-files.sh` can no longer happen, so the script's exit-2 "cannot find helper" guards are gone; `verify state` no longer prints `gap-drift: degraded — check-gap-drift.sh not found beside verify-state.sh` (the checker is always available) and its checker run is no longer bounded by a 5-minute timeout. |
