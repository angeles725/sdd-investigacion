### consumers (#2758)

| Tool | Description |
|---|---|
| `rsdd maint consumers [--repo DIR]` | Read-only lister of the live kit scripts that states what the search cannot see (issue #2758, phase 8 slice 1; the references to the scripts come with the next change), package `rsdd/internal/maint/consumers`. It reads the file list from git (`git ls-files -z --cached --others --exclude-standard`: tracked files plus untracked files that are not ignored, so an uncommitted file counts), builds the live script list from the tree on each run (files under `research-sdd/toolbelt/`, `research-sdd/templates/` and `research-sdd/install/` with the extension `.sh`, `.py`, `.mjs`, `.cjs`, `.js`, `.ts` or `.java`), and prints the repository, the kit, the files listed, the script count by extension, the basenames that two or more live scripts share, each exclusion of the script list with the number of files it removed (a name containing `.test.`, a `fixtures` directory, `node_modules`), the line that says the Go module is not enumerated by this version, and the limits of the search on every run (names that arrive through a flag or an environment variable, names built at run time, globs, names without the extension, everything outside the repository, that a match is a whole-name occurrence in text, not proof of a call, and that files ignored by git and the contents of submodules are not listed). It reads no file: only the names that `git ls-files` gives. The git children run without `GIT_DIR`, `GIT_WORK_TREE`, `GIT_COMMON_DIR` and `GIT_INDEX_FILE`, so `--repo` wins over the caller's environment. `--repo` defaults to the work tree that holds the working directory. Exit codes: 0 report printed, 1 operational (`absent-input`: no script directory file, or a `--repo` that is not a directory; `empty-input`; a git that failed, timed out or hit its output cap), 2 usage error, 3 degraded (git is not on PATH, the directory is not inside a work tree, or `git ls-files` wrote on stderr with exit code 0; no count is printed). |
