### consumers (#2758)

| Tool | Description |
|---|---|
| `rsdd maint consumers [--repo DIR]` | Read-only enumerator of the references to a kit script (issue #2758, phase 8 slice 1), package `rsdd/internal/maint/consumers`. It reads the file list from git (`git ls-files -z --cached --others --exclude-standard`: tracked files plus untracked files that are not ignored, so an uncommitted file counts), builds the live script list from the tree on each run (files under `research-sdd/toolbelt/`, `research-sdd/templates/` and `research-sdd/install/` with the extension `.sh`, `.py`, `.mjs`, `.cjs`, `.js`, `.ts` or `.java`), and prints the repository, the kit, the files listed, the script count by extension, the basenames that two or more live scripts share, each exclusion of the script list with the number of files it removed (a name containing `.test.`, a `fixtures` directory, `node_modules`), the line that says the Go module is not enumerated by this version, and the limits of the search on every run (names that arrive through a flag or an environment variable, names built at run time, globs, names without the extension, everything outside the repository, and that a match is a whole-name occurrence in text, not proof of a call). `--repo` defaults to the work tree that holds the working directory. Exit codes: 0 report printed, 1 operational (`absent-input`, `empty-input`, a listed file that cannot be read), 2 usage error, 3 degraded (git is not on PATH, or the directory is not inside a work tree; no count is printed). |
