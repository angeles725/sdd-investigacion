### plan-review-slices (#1276)

| Tool | Description |
|---|---|
| `rsdd lint review-slices [--cwd DIR] [--base-ref REF] [--max-lines N]` (shim `plan-review-slices.sh`) | Go port (kit issue #2270, T8a of the kit-improvements campaign) of the review-slice planner, package `rsdd/internal/lint/reviewslices` (`reviewslices.go` the git walk and the typed refusals, `plan.go` the greedy grouper and the numstat reader). The registry row `plan-review-slices.sh` above and `plan-review-slices.v1.md` still describe what it prints and its exit contract (0 plan or `EMPTY-RANGE` · 2 usage / not a repository / bad ref / unreadable git answer · 3 git missing), byte for byte: it makes the same git calls in the same order, so a failure of any one of them is the same typed exit 2 and a failed parent lookup never reads as a root commit. The commits are measured four at a time and consumed in commit order, so the output, and the slices already printed when a later commit fails, are the script's (`TestMeasureAllYieldsInCommitOrderAndStopsAtTheFirstFailure`, the `git-*-on-the-*-commit` scenarios). Pinned by a differential test against the frozen script (`internal/lint/reviewslices/testdata/legacy`, sha256 pinned) over every flag, usage error, typed state and git failure the script has (stdout, stderr and exit code, on one shared repository per builder, and the repository unchanged afterwards), by the recorded answers of that run (`testdata/golden/scenarios.json`, replayed where there is no bash), by the guard tests of `units_test.go` (the table at its head lists each former shell mutant and the test that now kills it) and by the goldens of `internal/lint/testdata/golden/review-slices-*`. `tests/plan-review-slices.test.sh` is the black-box check of the shim. Registered `PlainExit3`: exit 3 is the script's `DEGRADED: git not found` on stdout, with nothing on stderr. |

Intended divergences from the bash tool (each pinned by a scenario of the differential test that asserts the declared answer AND that the script differs; everything else is byte-identical):

| Divergence | Legacy script | Port |
|---|---|---|
| `--max-lines` above int64 is refused (`max-beyond-int64-*`, golden `review-slices-max-beyond-int64`) | `[ "$cl" -gt "$max" ]` failed with `integer expression expected` and was read as false: no commit was ever `UNSPLITTABLE`, no two commits ever shared a slice, and the plan ended `max=9223372036854775807` with exit 0. | exit 2, `plan-review-slices: --max-lines must be a positive integer no larger than 9223372036854775807 (got '<v>')` on stdout. |
| awk is no longer a dependency (`awk-is-not-needed`) | With no awk on `PATH` every commit measured `lines=0` (`awk: command not found`, then `integer expression expected` on stderr) and the plan exited 0: a silent zero. | The numstat is read in Go; the plan is right with only git on `PATH`. |
| A numstat count beyond int64 is a malformed row (`numstat-huge-count`) | The awk summed it as a float and the later `[ -gt ]` failed on it. | exit 2, `plan-review-slices: malformed numstat row for <sha>`. Real git never prints such a count. |
| Every git child is bounded (10 minutes, `core/kitmaint`) | Unbounded. | A timeout is the same typed failure as a non-zero git exit. |
