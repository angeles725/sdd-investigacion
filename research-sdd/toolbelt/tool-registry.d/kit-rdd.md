### kit-rdd (#2394)

| Tool | Description |
|---|---|
| `rsdd maint rdd-start [--consent granted] [--base-ref REF] [--agent NAME] <cwd> <outfile>` / `rsdd maint rdd-drive [--max-steps N] <cwd> <first-json-file>` | Go port (kit issue #2394, epic #2270) of the former Python `maint/kit-rdd-start.py` and `maint/kit-rdd-drive.py`; their registry rows above still describe the contract, unchanged (exit states, allowlist, consent rule). `maint/kit-rdd-start.sh` and `maint/kit-rdd-drive.sh` are the compatibility shims that hand over to `lib/rsdd-exec.sh` (`$RSDD_BIN`, then `<kit>/bin/rsdd`), so `maint/kit-pr-pipeline.sh` is unchanged; they are removed in phase 8. Intended differences from the Python tools: the usage text is `rsdd`'s own; exit 3 also writes `DEGRADED: missing runtime dependency: gentle-ai` on stderr; stdout appears when the command returns (not line by line); a capture's `NON-JSON` diagnostic is logged in provider order after the concurrent captures finish; the provider commands run in their own process group under a 6 h bound. Suites: `tests/kit-rdd-start.test.sh`, `tests/kit-rdd-drive.test.sh`, `tests/kit-pr-pipeline.test.sh` (black box through the shims) and the Go tests in `rsdd/internal/maint`. |
