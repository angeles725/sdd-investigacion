### migrate-backlogs (#2684)

| Tool | Description |
|---|---|
| `rsdd corpus migrate-backlogs <corpus-dir>` | Go port (kit issue #2684, epic #2270) of `migrate-backlogs.sh`; the registry row `migrate-backlogs.sh <corpus-dir>` above still describes what it does and prints, line for line: `PROPOSE <label> <file>` plus the unified diff (`--- a/<file>`, `+++ b/<file>`, three lines of context, GNU hunk headers), `MANUAL <label> <reason> rows=<N> first-line=<L>`, `ok`, `empty-input:`, `absent-input:` and the closing summary. Exit 0 inspected · 1 operational failure (typed `degraded: migrate-backlogs: ...`, stderr, no closing summary) · 2 bad args or a target that is not a directory. `migrate-backlogs.sh` is a compatibility shim that hands over to `lib/rsdd-exec.sh`; it is removed in phase 8. The command only reads the target (the whole tree is hashed before and after every parity case, refusals included) and starts no subprocess: the awk programs, `find`, `sort`, `mktemp` and `diff` of the script are computed in process. The frozen script and its `lib/state-files.sh` are the parity oracle of the differential test (`internal/corpus/migratebacklogs/testdata/legacy`). |

Intended divergences of `rsdd corpus migrate-backlogs` from the frozen script. Every parity case (the cases of `internal/corpus/migratebacklogs/cases_test.go`, replayed from `testdata/golden/cases.json` and run live against the script by `TestDifferential`) is byte-identical on stdout, stderr and exit code, except where a row below says otherwise; each row is pinned by a test of `internal/corpus/migratebacklogs/divergence_test.go` that asserts the whole output and the exit code.

| Divergence | Legacy script | Port |
|---|---|---|
| A file without a final newline keeps it (`TestFileWithoutFinalNewlineIsNotProposed`, `TestRewrittenLastLineKeepsTheMissingNewline`, `TestFocusesWithoutFinalNewline`, `TestSkeletonTerminatesTheLastLine`) | awk printed a newline after the last line, so every state or FOCUSES file that lacked one got a spurious one-line `PROPOSE` (a diff whose only change was the terminator), even when there was nothing to migrate. | Line endings are preserved byte for byte. Nothing to migrate prints `ok <label>: nothing to migrate`; a rewritten last line keeps `\ No newline at end of file` on both sides; only an appended skeleton terminates the line before it. |
| A CRLF file is read like its LF self and keeps its line endings (`TestCRLFFileIsReadAndKeepsItsLineEndings`) | The `\r` before the closing pipe was an extra cell: every row was `malformed-row`, no heading was recognised (`## Gap backlog\r`), and the tool proposed nothing but the spurious end-of-file change. | The terminator is not part of the line. Headings, rows and FOCUSES.md are recognised, and each rewritten line keeps its `\r\n`. |
| A table ends at the first line that is not a row (`TestSecondTableHeaderIsNotADataRow`, `TestLooseRowsAfterABreakAreNotRewritten`) | The table state (separator seen, width) lasted until the next `## ` heading. The header of a second table in the same section was read as a data row: `malformed-row` or `unknown-priority`. Loose rows after a blank line were rewritten as if they belonged to the first table. | A header with no separator before it is printed untouched; a second table starts clean (its own width check). A row after a break with no header and separator of its own is prose and is left alone. |
| The qualifier moved to the Status cell keeps its case (`TestQualifierKeepsItsCase`) | `med (Cross-Vibra B4)` became `pending (cross-vibra b4)`: the free text of §8b was lowercased with the tier. | `pending (Cross-Vibra B4)`. The tier is folded, the qualifier is copied as written. |
| A blank Status cell takes the qualifier between single blanks (`TestQualifierOverABlankStatusCell`) | `setcell` kept the blanks of a cell with no text on both sides of the new text (`\|  (x) \|` from a one-blank cell). | `\| (x) \|`. The row also reports `unknown-status-token`, as before. |
| A symlinked corpus directory is followed (`TestSymlinkedCorpusDirectoryIsFollowed`) | `find "$target"` does not dereference its starting point: the link was searched as a file, nothing was found, and the run said `absent-input: no RESEARCH-STATE*.md`. | The corpus directory is followed (a symlink to a directory below it is still not entered, like `find`). |
| A trailing slash on the target does not reach the diff labels (`TestTrailingSlashDoesNotLeakIntoTheLabels`) | `${f#"$target"/}` did not match `dir//file`, so the labels read `a/dir/RESEARCH-STATE-x.md`. | Names are relative to the corpus whatever the spelling of the target. |
| `/.git/` is excluded below the corpus only (`TestCorpusUnderADotGitDirectoryIsRead`) | `-not -path '*/.git/*'` matched the corpus's own location: a corpus under a directory named `.git` was reported as having no state files. | `.git` directories are not entered; the path of the corpus itself is not tested. |
| A directory named like a state file is not one (`TestDirectoryNamedLikeAStateFileIsSkipped`) | `find` listed it and awk failed on it: `degraded: ... awk failed on`, exit 1. | Directories are skipped; their contents are still searched. |
| Proposals are positional, hunks are GNU's (`TestTieLinesArePrintedPositionally`, `TestUnifiedDiffShapes`) | `diff -u` found a minimal script itself: when a rewritten line equalled an adjacent line it could print the hunk shifted by one. | The transforms rewrite lines in place and append a tail, so lines pair by position and the hunks (3 lines of context, merge at 6 unchanged lines, `,count` dropped at 1) are those of GNU diff. In the tie case the hunk is the positional one, still a valid patch. Real backlogs have distinct gap ids per row, so no parity case differs. |
| The shell's degraded lines are gone, three remain (`TestUnlistableCorpusIsDegradedNotAbsent`, `TestUnlistableSubdirectoryIsDegradedNotAbsent`, `TestUnreadableStateFileStopsTheRun`) | `required tool '<v>' not found`, `cannot find helper`, `helper <v> failed to define list_state_files`, `mktemp failed`, `awk failed on`, `awk failed reading`, `diff failed (status <v>) on`, `find failed while scanning`, and the two `scanning <v> for ... failed (status <v>)` lines. | No tool, helper or scratch directory is involved, so those reasons cannot happen. `degraded: migrate-backlogs: cannot read <file> — proposal not computed`, `<dir> is not readable/traversable (<error>) — cannot scan` and `scanning <dir> failed (<error>) — cannot tell absent from unreadable` (one walk lists both file kinds) remain, with exit 1 and no closing summary. A FOCUSES.md that cannot be read is not a registry saying `document` (as before); the FOCUSES pass reports it. |
| The usage line names the command (`args-none` of the parity cases, normalised) | `usage: migrate-backlogs.sh <corpus-dir>` | `usage: rsdd corpus migrate-backlogs <corpus-dir>`, exit 2 as before. |

Kept on purpose, with a parity case each: a row with an escaped pipe in a backlog section is `malformed-row` (never guessed, `malformed-escaped-pipe`); the separator row is recognised by its first cell alone (`sep-first-cell-only`); a leading `open`/`queued` token is rewritten only when it is the whole first word of the Status cell (`status-*`); `FOCUSES.md` is only transformed when a state file was found (`state-only-focuses-is-absent-input`); a `document` focus is matched exactly, never by substring (`doc-*`).
