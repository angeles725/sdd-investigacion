### stage-retro (#2663)

| Tool | Description |
|---|---|
| `rsdd retro stage [--toolbelt DIR] <retro.md> [--force]` | Go port (kit issue #2663, epic #2270) of `stage-retro.sh`; the registry row `stage-retro.sh <path-to-retro.md>` above still describes what it does and prints, byte for byte, and its exit contract holds (0 staged; 1 usage; 2 excluded or already applied\|dismissed; 3 dirty kit repo; 4 git cannot report the repo state; 5 branch cannot be created or checked out; 6 fetch failed; 7 self-referential retro not on origin/main; 8 retro unreadable after the checkout). `stage-retro.sh` is a compatibility shim that hands over to `lib/rsdd-exec.sh` and passes its own directory as `--toolbelt`; it is removed in phase 8. `lib/retro-status.sh` and `lib/target-paths.sh` stay (other scripts still source them): the port reads the marker through `core/retrogrammar` and the target name through `core/kit`, and the frozen script and the two libraries are the parity oracle of the differential test (`internal/retro/stage/testdata/legacy`). |

Intended divergences of `rsdd retro stage` from the frozen script. Every parity case (the 47 cases of `internal/retro/stage/cases_test.go`, replayed from `testdata/golden/cases.json` and run live against the script by `TestDifferential`) is byte-identical on stdout, stderr and exit code and leaves the same repository state, except where a row below says otherwise; each row is pinned by a test of `internal/retro/stage/divergence_test.go` (or the `keepsHead` flag of the parity cases) that asserts exit code, stdout, stderr and the git state.

| Divergence | Legacy script | Port |
|---|---|---|
| The checkout is not switched to `main` first (`TestStartsFromAnotherBranchWithoutCheckingOutMain`, `TestMainHeldByAnotherWorktreeDoesNotBlockStaging`, `keepsHead` cases `parity/16c`-`16e`) | `git checkout -q main` ran before anything else. It moved the shared kit checkout for nothing (the branch is created from `origin/main`), left it on `main` after every refusal, and failed with exit 4 `cannot checkout main` whenever `main` was checked out in another worktree. | The checkout stays where it is until the retro branch exists. Exit 4 is now `degraded: git ... the state of the kit repo` (below). The self-referential guard compares the branch `main` with `origin/main`, as it did once the script had switched to `main`. |
| Exit 8 returns to where the run started (`TestExit8ReturnsToTheStartingBranchAndTheBranchIsDeletable`, `TestExit8FromAnotherBranchReturnsThereNotToMain`, `TestExit8FromADetachedHeadReturnsToTheCommit`, `TestExit8SwitchBackFailsIsReportedTruthfully`) | "Switched back to main", always. | "Switched back to `<branch>`" (the commit, `checkout --detach`, when HEAD was detached); the delete advice names the same checkout. From `main` the text is unchanged. |
| A branch name git refuses is found before any change (`TestInvalidBranchNameRefusedBeforeAnyChange`) | `retro/<target>-a..b`, `...-x.lock` or `...-trail.` failed only at `git checkout -b`, after `checkout main` and the fetch (exit 5 `cannot create branch`). | `git check-ref-format` runs with the clean-tree check: exit 5, `stage-retro: '<branch>' is not a valid branch name (target '<t>', file '<f>') — nothing was changed; ...`, no fetch, no checkout. |
| An empty slug is distinct per file (`TestNonASCIIFileNamesGetDistinctStableBranches`) | A file name with no `[A-Za-z0-9._-]` byte (`日本.md`) gave the slug `""`: the branch `retro/<target>-` was shared by every such retro, so a second one silently checked out the first one's branch. | The slug is `retro-<first 8 hex of the SHA-256 of the file name>`: stable per file, distinct between files. |
| A word after the retro that is not `--force` is refused (`TestUnknownArgumentRefusedBeforeAnyGitCall`, `TestForceReStagesAnAppliedRetroAndSaysSo`) | Only `$2 == --force` was read; `--forse` or a third word was ignored and the retro was staged. With `--force` the refusal advice `(Use --force to re-stage.)` was still printed. | Exit 1, `stage-retro: unknown argument '<word>' (the only option after the retro is --force)`, before any read or git call. With `--force` on an applied\|dismissed retro: `This retro is already '<s>' — re-staging because --force was given.` |
| A section that runs to the end of the file keeps its last line (`TestSectionAtEndOfFileKeepsItsLastLine`, `TestSection`) | `sed -n '/^## Proposed kit deltas/,/^## /p' \| sed '$d'` removed the last printed line to drop the closing heading; with no heading after the section that line was content (the last delta row). | Only a closing `## ` heading is dropped. Two matching headings in one file still print both ranges, the first range's closing heading included, as the script did (`parity/08c`). |
| A retro with no `## Proposed kit deltas` section warns (`TestMissingDeltasSectionWarns`) | Nothing was printed between the banner and the next steps. | The same stdout, plus `WARN: no '## Proposed kit deltas' section found in <retro> — there are no deltas to print.` on stderr. |
| A kit root that git cannot read is exit 4, typed (`TestKitRootThatIsNotARepositoryIsRefused`, `TestNoGitOnThePathIsATypedDegradedExit`) | `git status --porcelain` was unchecked: a kit root that was not a repository, or no git, read as a clean tree. | `degraded: git could not read the state of the kit repo in <dir> (<error>) — nothing was changed.` or `degraded: git not found on PATH — cannot read the state of the kit repo; nothing was changed.`, exit 4, git's own stderr first. |
| `git fetch origin` is bounded (`TestFetchThatHangsTimesOutAsADegradedExit`) | Unbounded. | 120 s (`Options.FetchTimeout`); a timeout is the same `degraded: git fetch origin failed` line, exit 6, preceded by `git: timed out after <d>: git fetch -q origin`. |
| An unreadable retro is refused before git runs (`TestUnreadableRetroIsRefusedBeforeAnyGitCall`) | It read as "no marker": the branch was created and the run ended with exit 8 after the checkout. | `degraded: retro not readable: <retro>`, exit 1, no git call. |
| Single quotes in the suggested commands are escaped (`TestSingleQuotesInTheSuggestedCommandsAreEscaped`) | A quote in the target label or in the retro's file name ended the quoting of `-m '...'`, `-m 'Retro: ...'` and `--title '...'`. | `'` becomes `'\''` inside those words. |
| `cannot find helper` / `failed to define retro_review_status` / `target_name_for_retro` exits are gone (`TestNoHelperFilesAreNeeded`) | Shell wiring: the script sourced two libraries and failed closed when one was missing or empty (exit 1). | The marker grammar and the registry reader are linked in; the port runs with no `lib/` beside it. The shim reports a missing rsdd binary (`degraded: rsdd-unavailable`, exit 2) instead. |
