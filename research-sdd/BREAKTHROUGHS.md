# Research-SDD — Breakthrough Ledger

Cross-target index of the DECISIVE solutions — the technique that finally cracked each target — so they
stay findable instead of buried in the corpus. Full doctrine: [`METHODOLOGY.md` §22](METHODOLOGY.md).

- A block earns a row here by declaring `**Breakthrough:**` in its header blockquote (§22.1). The field
  is ORTHOGONAL to the `[CERT*]` markers: those state evidence strength, this states crown-jewel-ness.
- This registry is **never auto-edited** (§8), exactly like `TARGETS.md`: the human — or a research-loop
  session working on that target — writes the row after tagging the block. `sweep-breakthroughs.sh`
  PROPOSES rows and WARNs on drift; it never applies (propose-never-apply).
- Back-fill is **target-owned** (§22.4): the kit reads target corpora but never writes them, so tagging
  a block is the operator's act. Populate this table only from VERIFIED block pointers, never by grep
  over prose.
