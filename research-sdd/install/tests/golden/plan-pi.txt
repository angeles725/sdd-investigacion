  | ## Research-SDD
  | 
  | Run the `research-sdd` skill to drive the investigation loop. It is a THIN launcher; the
  | single source of truth is the kit (`$RESEARCH_SDD_KIT`, else the default checkout).
  | Skill file: {HOME}/.pi/agent/skills/research-sdd/SKILL.md
  | Kit path: ~/.pi/agent/research-sdd/profile/general
  | Kit checkout: {KIT}
  | Read the prompts from Kit path; registry/ledger edits (TARGETS.md, BREAKTHROUGHS.md,
  | INSTALLED-TOOLS.md) and toolbelt runs go to Kit checkout, never the profile copy.
  | 
  | Session hooks: the research-sdd-hooks extension (installed with this launcher) runs the session-start
  | sweeps and the skill-drift check and injects their output into your context (system prompt section
  | `research-sdd-session`), and it gates the end of a turn with the retro and return-token gates (a block
  | comes back once as a message to act on). While that section is present do NOT re-run the sweeps by hand.
  | 
  | Session-start sweep FALLBACK (only when that section is absent, says DEGRADED, or says the sweeps
  | are still pending after your first reply): run MANUALLY; all read-only, degrade to silence on failure:
  |   Single command (recommended): `{KIT}/toolbelt/sweep-all.sh`
  |   Individual scripts (canonical; sweep-all.sh runs these in sequence):
  |   - `{KIT}/toolbelt/sweep-retros.sh`        — pending section 18 self-retrospective proposals
  |   - `{KIT}/toolbelt/sweep-audits.sh`        — pending section 13 audit reports
  |   - `{KIT}/toolbelt/sweep-breakthroughs.sh` — unindexed/drifted section 22 breakthrough ledger entries
  |   - `{KIT}/toolbelt/verify-registry.sh`     — TARGETS.md master-table drift
  |   - `{KIT}/toolbelt/verify-kit-clean.sh`    — kit dirty / unpushed warning
  |   - `{KIT}/toolbelt/sweep-tools.sh`         — unrecorded tools across all targets
  |   - `{KIT}/toolbelt/verify-tool-catalog.sh` — installed tools missing a capability-catalog entry
  |   - `{KIT}/toolbelt/verify-skill-drift.sh`  — deployed SKILL.md(s) diverged from kit source
  | 
  | Session-end retro (MANDATORY — the extension blocks a finished run ONCE when the retro is missing, and
  | says so when it could not check): the run is not over until the retro exists. Once it is written,
  | seed its deltas by hand:
  |   `{KIT}/toolbelt/stage-retro-issues.sh <retro> --apply`
