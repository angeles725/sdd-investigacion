## Process lessons
- A network drop makes `gh pr checks` print an error that a naive wait loop reads as "no pending"; right after a
  push the previous run's failed checks are still listed — wait until checks go pending before the merge helper.
- GitHub can return Internal Server Error on push and PR create; retry with backoff, never assume success.
- Subagent hand-back reports sometimes never arrive; check the worktree log and ask for the report.
- A fleet sweep for a parser must be driven by the artifact it parses (`find -name FOCUSES.md`), not TARGETS.md.
- Never `sed -i` with an unvalidated line-number variable (an empty value rewrote a whole file).
- A fixed-size mutant (Z1 inflate tooth) loses its teeth when the measured artifact grows; size it from the input.
- `run-all.sh` under heavy concurrent load needs a private TMPDIR; local quiet-tree runs were not always feasible,
  so CI was the full-suite gate for several PRs (merge-gate refuses without green CI).
